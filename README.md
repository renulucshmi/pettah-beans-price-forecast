# Pettah Beans Price Forecast

Forecasting next week's average wholesale price of beans at Pettah market, Sri Lanka, using bagging, boosting, stacking and an RF + ARIMA hybrid.

**Author:** Prakasan R. (224152U), University of Moratuwa

## Dataset
Central Bank of Sri Lanka, Daily Price Report, via Macro Lab (macrolab.lk). Daily wholesale and retail food prices, Aug 2016 to Nov 2026.
